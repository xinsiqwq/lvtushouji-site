Available-source limitation:
The browser factory was extracted from an existing locally cached compiled
bundle. The matching cached WASM resource was selected through that bundle's
original hashed asset reference. Its precise upstream commit/version has not
been established. The included C/JavaScript source is the available upstream
source snapshot; correspondence between that snapshot and the cached WASM has
not been verified. No exact-matching revision or fresh WASM rebuild is claimed.
See manifest.json for file hashes and source.zip for the reviewed source bundle.

Changes by the travel-notebook project, 2026-10-12:
- Browser-only factory extraction, independent of the old Vue application UI.
- Correct backing-pixel comparison when devicePixelRatio exceeds one.
- Same-origin iframe messaging, real state reporting and pausable RAF lifecycle.
- Explicit native name aliases for the UI's 25 stars and 88 constellations.
- Chinese translateFn, Chinese font subsets and western name records.
- Star child masks constrained to the local test snapshot's real child files.
These engine adapters and preparation tools are distributed under AGPL v3.

apps/test-skydata sample. The star data retain their recorded skysource hash.
